    Как считается ликвидность

    Supreme Values — балл 0–100 по данным сайта: спрос (Demand × 10, не указан — 0), стабильность (), узкий диапазон цены (до 5%) +5, широкий (больше 20%) −5.

    Площадки — балл 0–100 по продажам за неделю (если площадка их показывает), числу предложений и тому, сколько предложений исчезло между проверками (их купили). Чем больше продаж и предложений, тем легче продать предмет.

    Общая — среднее Supreme Values и всех площадок, где есть данные по предмету.

    Ликвидные — 60 и выше, средние — 30–59, неликвидные — меньше 30. Секретные предметы и Untradables в колонки не попадают.
